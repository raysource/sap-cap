常见「看起来像好了」的坑
  • cds compile 打印了 [ERROR] 但退出码仍是 0 —— 别只看有没有输出，要看有没有 [ERROR]（第 4 节②会用到这一条）。
  • npm run deploy 失败时 SQLite 文件可能已生成但没有表；用第 4 节①的命令核对表清单，不要凭文件名判断。
